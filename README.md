素材下载器 · 使用说明
====================

一个绿色小工具：把抖音 / 小红书的分享链接粘进去，勾选想要的内容，
存成电脑上的图片和视频

一、怎么安装 / 打开
------------------
【便携版】
  解压整个 zip → 双击文件夹里的「素材下载器.exe」。
  · 必须在解压出来的文件夹里运行，把 exe 单独拖出来会打不开
【源码版】
双击run.bat进行执行，需要python环境



二、怎么用
----------

1. 在抖音/小红书里点「分享 → 复制链接」。
2. 打开本软件，点「粘贴」，把整段文字贴进去没关系（程序会自己挑出链接），
   然后点「解析」。
3. 中间会出现清单：
   图片 / 视频 / 实况（实况会存成一段 mp4，本身就是视频，不用转换）。
   想只下载其中几张，就把不想要的点掉（点最左边的方框，或者按空格）。
4. 点「下载选中」，选个文件夹，等进度条走完就行。
   下载完会自动帮你打开那个文件夹（可在「设置」里关掉）。



三、常见问题
------------

Q：Windows 提示「已保护你的电脑 / 未知发布者」？
A：因为这个 exe 没有买代码签名证书。需要以管理员身份运行，点「更多信息 → 仍要运行」即可。
   个别杀软会把这类打包软件误报，加个信任就行。

Q：安装时提示 安装包不完整 / 损坏？
A：多半是下载没下完。重新下一次（安装版应该在 12 MB 左右）。

Q：下载的文件在哪？
A：你选的那个文件夹。历史记录里也能看到，双击一行直接跳到文件所在位置。

Q：数据存在哪？
A：%APPDATA%\VideoSaver（配置、下载历史、预览缓存都在这里）。
   想恢复出厂设置：删掉这个文件夹即可，不会影响你下载好的文件。

Q：会偷传我的东西吗？
A：不会。程序只做两件事：请求分享页、以及（抖音）请求你在设置里配的解析接口。
   没有登录、没有统计、没有远程配置。
